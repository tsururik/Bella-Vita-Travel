# Bella Vita Travel — Italian Grand Tour

Готовый учебный сайт: кинематографичное путешествие Minsk → Vilnius → Rome → Florence → Venice → Vilnius → Minsk.

Данные согласованы с презентацией: **17–24 апреля 2027, 8 дней / 7 ночей, от €1 650, группа 20 человек**. Рим: 17–20 апреля; Флоренция: 20–22; Венеция: 22–24. Маршрут через Вильнюс взят из задания и слайда 6 (упоминание Стамбула на слайде 8 не используется).

**Онлайн-версия:** https://tsururik.github.io/Bella-Vita-Travel/ — публикуется из папки `dist` через GitHub Actions (`.github/workflows/deploy.yml`) при каждом push в `main`.

## Запуск

Нужен Node.js 18+:

```bash
npm install
npm run dev
```

Открыть **http://127.0.0.1:4173**. Внешних npm-зависимостей нет; `npm install` можно пропустить.

Альтернатива — Python 3:

```bash
python3 -m http.server 4173 --directory dist
```

Открыть **http://localhost:4173**. Все ресурсы хранятся локально; интернет при демонстрации не требуется. Предпочтителен современный Chrome, Edge или Safari. Не открывайте через `file://` — используйте сервер.

## Структура и редактирование

- `dist/index.html` — все сцены, заголовки, программа, цена, форма, билет. Основные тексты меняются здесь.
- `dist/styles.css` — палитра в `:root`, шрифты, композиция, адаптивность и CSS-анимации.
- `dist/app.js` — анимации, маршрут (`stages`), подписи галереи (`romePhotos`), взаимодействия и демонстрационная форма. Базовая цена `1650` для расчёта суммы и число дней `8` должны обновляться вместе с HTML.
- `dist/assets/images/` — локальные JPEG. Для замены сохраните новое фото под тем же именем или измените `src` в HTML/`romePhotos`. Обновите `alt`, размеры и источник.
- `dist/assets/fonts/` — реальные Google Fonts: Cormorant Garamond и Manrope, локальные копии.
- `dist/assets/vendor/` — GSAP 3.13.0, ScrollTrigger 3.13.0, Lenis 1.3.11.
- `dist/credits.html` и `PHOTO-SOURCES.json` — авторы, источники и лицензии фотографий.
- `dist/email-config.js` — ключи EmailJS для отправки билета на почту (см. «Почта»).
- `email/ticket-template.html` — HTML-шаблон письма с билетом для EmailJS.
- `dist/assets/ticket/` — рисунок городка, самолёт, штрихкод и оливковая ветвь для билета; вырезаны из шаблона билета, используются на сайте и в письме.
- `server.mjs` — простой сервер без зависимостей.
- `.openai/hosting.json` — настройки размещения Sites.

## Что показать на занятии

1. Открыть страницу на 1440×900 или развернуть браузер. Короткий loader открывает панораму Рима.
2. **Start your journey** — пролёт по кривой Minsk → Vilnius → Roma. Можно пропустить кнопкой Skip.
3. Прокрутить карту: маршрут рисуется, транспорт и подписи этапов меняются, маршрут возвращается в Минск.
4. **Explore Rome** — полноэкранная галерея. Работают подписи, стрелки, клавиши ← →, Escape.
5. Прокрутить поезд до Флоренции, перетащить галерею мышью либо использовать стрелки/свайп.
6. **Take a gondola ride** — сменить панораму на тихий канал. Повторное нажатие возвращает Grand Canal.
7. **Book your journey** — заполнить имя, фамилию, число путешественников, дату и email. Сумма обновляется.
8. **Confirm journey** — самолёт, финальная надпись и персональный билет с номером брони. Возврат автоматически через 7 дней после выбранной даты: 8 календарных дней тура. Если почта настроена, тот же билет уходит письмом на указанный email (нужен интернет).

## Важные особенности

- Это **демонстрация бронирования** без оплаты и реальных броней. Единственный запрос — письмо с билетом через EmailJS: имя, фамилия, email, даты и число путешественников уходят в EmailJS и с ящика агентства на указанный адрес. Пока `email-config.js` не заполнен, ничего не отправляется.
- Имя выводится через `textContent`; данные не сохраняются в localStorage/cookies.
- Нативные `<dialog>` удерживают фокус, закрываются по Escape и возвращают его на исходную кнопку.
- Учитывается `prefers-reduced-motion`; при включении уменьшения движения эффекты отключаются.
- На телефоне есть свайп галереи, упрощённая компоновка и сохранены все основные действия.
- Google Fonts, библиотеки и 11 фотографий хранятся локально. Вес сайта около 6–7 МБ, без видео; фото ниже первого экрана загружаются лениво.
- Дополнительный read-only WebMCP-инструмент `get_italian_journey` регистрируется только в поддерживающем его браузере. Обычная работа сайта от него не зависит.

## Почта

После подтверждения брони гостю приходит письмо с билетом на его имя и фамилию с ящика **krokbuslikovAI@ya.ru**. Сайт статический, поэтому письмо отправляет сервис [EmailJS](https://www.emailjs.com) (бесплатно до 200 писем в месяц). Пароль от Яндекса хранится только в EmailJS и на сайт не попадает.

Настройка делается один раз:

1. **Яндекс.** Войти в krokbuslikovAI@ya.ru → Почта → Настройки → «Почтовые программы» → включить «С сервера imap.yandex.ru по протоколу IMAP» и «Пароли приложений». Затем на id.yandex.ru → Безопасность → «Пароли приложений» создать пароль для «Почты» и скопировать его.
2. **EmailJS: сервис.** Зарегистрироваться на emailjs.com → Email Services → Add New Service. Если в списке есть Yandex — выбрать его, иначе «SMTP server»: хост `smtp.yandex.ru`, порт `465`, SSL включён. Логин — `krokbuslikovAI@ya.ru`, пароль — пароль приложения из шага 1. Скопировать **Service ID**.
3. **EmailJS: шаблон.** Email Templates → Create New Template:
   - **Subject:** `Buon viaggio, {{first_name}}! Your Italian journey ticket {{booking_ref}}`
   - **To Email:** `{{to_email}}` (или `{{email}}` — сайт передаёт оба)
   - **From Name:** `Bella Vita Travel`
   - **Reply To:** `krokbuslikovAI@ya.ru`
   - **Bcc** (по желанию): `krokbuslikovAI@ya.ru` — копии всех заявок будут приходить агентству.
   - **Content** → Edit Content → Code: вставить содержимое `email/ticket-template.html`. Скопировать **Template ID**.
4. **EmailJS: ключ.** Account → General → скопировать **Public Key**.
5. Вписать три значения в `dist/email-config.js` и выполнить `git push` — сайт обновится сам.
6. **Защита от спама.** Account → Security: в «Allowed origins» указать `https://tsururik.github.io` (и `http://localhost:4173` для локального показа), включить ограничение частоты запросов.

Service ID, Template ID и Public Key не секретны — они и так видны в коде любого сайта на EmailJS.
