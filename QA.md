# Проверка первой версии

Проверено 5 октября 2026 в Chromium через Playwright.

- Desktop: 1440×900; mobile: 390×844.
- Ошибки JavaScript и console.error: **0**.
- Все локальные ссылки на ресурсы существуют, изображения загружаются, у всех есть alt.
- Нет горизонтального переполнения страницы, в том числе на каждой мобильной сцене.
- Loader исчезает; стартовый самолёт реально проходит промежуточные координаты кривой.
- После Start страница автоматически переходит к карте (scrollY 900 на desktop).
- Skip и повторный запуск стартовой сцены работают.
- На карте проверены начало, перелёт, поезд между городами, обратный перелёт и финальный трансфер до Минска.
- Rome: смена фотографий, подписи, стрелки, Escape.
- Florence: кнопки листания и перетаскивание действительно меняют scrollLeft (до 639 px на desktop).
- Venice: кнопка меняет aria-pressed, вид канала и подпись; второе нажатие возвращает панораму.
- Booking: пустая форма блокируется; 3 участника дают €4 950; имя с кириллицей отображается корректно.
- Билет: 17 апреля → 24 апреля; альтернативная дата 15 мая → 22 мая.
- Финал: пролёт самолёта, появление текста, билета и имени; повторное открытие формы работает.
- Reduced motion: Start без длительного пролёта; карта доступна; форма и финальный билет работают.
- Визуально проверены hero, карта, Rome, Rome gallery, Florence, галерея Tuscany, Venice, цена, форма, confirmation; отдельно mobile hero/form/ticket.
- Все данные формы остаются в памяти текущей страницы; запросов на бронирование нет.
- Синтаксис app.js проверен через node --check.

WebMCP — необязательная интеграция. Нативный поддерживающий контекст в тестовом Chromium недоступен; регистрация защищена feature detection. Валидация этого дополнительного API недоступна и не влияет на основные функции сайта.

Сайт не проверялся на реальных iOS/Android устройствах или во всех версиях Safari/Firefox. Это учебный клиентский проект, не система настоящего бронирования.
